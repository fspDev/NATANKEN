# NATÁNKEN 🦁🦒🐊

El parque de juegos de los animales: mini juegos infantiles para 1 a 4 jugadores en el mismo celular.

**Jugar:** https://fspdev.github.io/NATANKEN/

## Juegos
- **Memoria Animal** – encontrá las parejas (por turnos, todos en el mismo tablero).
- **Carrera Salvaje** – tocá tu botón lo más rápido posible (todos a la vez).
- **Suricatas Curiosas** – tocá a las suricatas, ¡no al cocodrilo!
- **Lluvia de Frutas** – mové al mono para atrapar frutas.
- **Canguro Saltarín** – saltá obstáculos y juntá frutas.
- **Fiesta de Globos** – reventá globos.

## Instalar en Android (funciona sin internet)
1. Abrí el link en Chrome.
2. Tocá **Instalar en el celu** (o menú ⋮ → *Agregar a pantalla principal*).
3. Listo: queda como una app y funciona sin conexión.

## Desarrollo
Sin dependencias ni build: HTML, CSS y JavaScript puro.

```bash
node tools/serve.mjs
```

Cada push a `main` se publica solo en GitHub Pages (`.github/workflows/deploy.yml`).
En el repo: *Settings → Pages → Source: GitHub Actions*.
